# EDA on Retail Sales Data

## Internship
Oasis Infobyte - Data Analytics Internship

## Project Overview
This project performs Exploratory Data Analysis (EDA) on retail sales data to identify sales patterns, customer behaviour, and product category performance.

## Objectives
- Analyze retail sales data using Python.
- Understand monthly and quarterly sales trends.
- Compare sales by gender, age group, and product category.
- Study relationships between numerical variables.
- Generate visualizations and business insights.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## Dataset
A sample retail sales dataset created for learning and demonstration purposes. It contains transaction dates, customer IDs, gender, age, product category, quantity, unit price, and total amount.

## Analysis Performed
- Dataset overview and descriptive statistics
- Missing values and duplicate checks
- Monthly sales trend
- Quarterly sales trend
- Sales by product category
- Sales by gender
- Sales by age group
- Numerical correlation heatmap

## Key Observations
- Sales vary across months and product categories.
- Product categories can be compared by their total revenue.
- Gender and age groups can be compared by total sales.
- The dataset is a sample, so results may not represent all retail customers.

## Business Recommendations
1. Monitor monthly and quarterly sales to identify stronger and weaker periods.
2. Compare category performance before planning inventory and promotions.
3. Analyze customer groups to develop more targeted marketing campaigns.
4. Use a larger real-world dataset before making major business decisions.

## How to Run
1. Install Python.
2. Install the required libraries:
   `py -m pip install pandas matplotlib seaborn`
3. Run the analysis:
   `py retail_sales_analysis.py`
